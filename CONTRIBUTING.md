# Contributing

This project uses [mise](https://mise.jdx.dev) for managing dev tools,
environment variables, and tasks.

## Setup

Install dev tools.

```sh
mise install
```

## Tasks

List available tasks with...

```sh
mise tasks
```

then run a task with...

```sh
mise run <task>
```

## Dev Tools

List available dev tools with...

```sh
mise list
```

then run a dev tool with...

```sh
mise exec -- <dev-tool>
```
