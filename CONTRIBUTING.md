# Contributing

This project uses [mise](https://mise.jdx.dev) for managing dev tools,
environment variables, and tasks.

## Tasks

List the available tasks.

```sh
mise tasks
```

Run a task.

```sh
mise run <task>
```

## Tools

List the available dev tools.

```sh
mise list
```

Run a dev tool.

```sh
mise exec -- <devtool>
```
